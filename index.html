Ops Reconciliation Monitor

A Python-built automated trade and cash break detection pipeline with root-cause classification and priority scoring. Designed to replicate and generalise reconciliation problem-solving patterns from financial operations — making intelligent break detection accessible beyond proprietary enterprise systems.

Raw trade data → Break detection → Root-cause classification → Priority scoring → Excel + Power BI output
Technical stack
  • Python — pandas, numpy, openpyxl, matplotlib
  • Modular pipeline: data generation → engine → reporting
  • Root-cause classifier — 8 break categories with logic rules
  • Priority scoring engine — High / Medium / Low by exposure
  • Power BI-ready CSV outputs for dashboard integration
Classification logic
  • Failed settlement detection
  • Large notional mismatch — duplicate identification
  • Price / quantity discrepancy flagging
  • FX conversion and rounding variance
  • Corporate action and income processing lag
